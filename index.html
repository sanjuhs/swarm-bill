What this bill leaves out.

A thousand agents on one site is a stunt.

Anthropic's docs suggest starting agent teams with 3 to 5 teammates, and warn that two teammates editing the same file overwrite each other.

Concurrency is capped.

DeepSeek lists a concurrency limit of 2,500 for Flash. A thousand agents fit. Five thousand would have to queue.

Thinking costs tokens.

Thinking mode is on by default, so real output can run well past 600 tokens a turn. Push the slider and see.

Someone still has to check it.

Tokens are the cheap part. Reviewing what a thousand agents produced is not on this receipt.
