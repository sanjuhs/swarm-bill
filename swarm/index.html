      What you're watching

      One agent, one job

      Each agent has a speciality and takes the next task whose prerequisites are finished. Nobody edits the same box at the same moment.

      Copy, then rewrite

      The second and third product cards start as copies of the first. One agent pastes, another rewrites the name and price, and another changes the colours.

      Notes come back

      The reviewer leaves comments on the canvas. Whoever does that kind of work picks up the note, fixes it and closes it.

      More agents stop helping

      This is a simulation. No model is running: a scheduler assigns the tasks and every click is scripted. The bill is a modelled estimate of 3 turns per task on DeepSeek V4.1 Flash at off-peak prices, using the same assumptions as Swarm Bill. Paper Kite Co. is made up.
